## About Me

Game developer and full-stack engineer specializing in **Flash/AIR game clients** and **real-time multiplayer systems**. I build, maintain, and optimize game ecosystems end-to-end — from low-level binary protocols and particle rendering engines to admin panels and DevOps tooling.

- Building and optimizing game clients with **ActionScript 3 / Adobe AIR**
- Developing game servers and backend services in **C#** and **PHP**
- Creating admin dashboards and web platforms with **Vue.js**, **TypeScript**, and **Laravel**
- Porting modern JavaScript patterns to ActionScript 3 for legacy codebase modernization
- Deep experience with **binary protocols**, **network analysis**, and **performance optimization**

**[byte-array-php](https://github.com/amorim778/byte-array-php)** — Modern, endian-aware byte buffer for PHP inspired by ActionScript's `ByteArray` and Java's `ByteBuffer`. Supports big/little-endian primitives, UTF strings, compression, Base64/hex conversion, and file I/O.

```bash
composer require byte-array/byte-array
```
